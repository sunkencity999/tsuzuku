# TSUZUKU - ARCHITECTURE: shared contracts (v1)

`docs/design/01-07` are the spec; on conflict **this file wins** (ids are hyphen-form `v-n5-0001`, card keys `v-n5-0001#prod`). Pseudo-TS: `s n b` = string number boolean; type-only cycles between contract files are fine.

## 0. Tiers and the import rule

- **Day 0:** the lead authors every `[CONTRACT]` file from the pseudo-TS in this document and commits them before the groups fork (they are fully specified here; no group waits on another group's contract). B ships `makeTestStore` on day 1 as an in-memory store with no reducers wired, so every group's tests run from day 1. `src/store/index.ts` re-exports only B-internal modules; the derived read-model that needs `@/learn` (`selectors`, `perapera`, `projection`) lives in `src/store/derived.ts`, which UI imports directly.

Exceptions: A's `src/app/pages.ts` + `src/main.tsx` import other groups' barrels to wire routes, exercises and services; and the **art tier `src/art/**` is open** — importable from every group (statically or through a deferred `import.meta.glob`) and itself importing only the contract tier (design 09 §12.1 d44/d64; `src/i18n/lint.test.ts` `OPEN_PATHS` enforces exactly this reading). All other cross-group behaviour flows through the bus, the exercise registry, the audio slot and the store.
- **Content pipeline scripts** (`scripts/{validate-content,assign-stations,build-content-index,linker}.ts`, owner C, `[P1]`) run under `node --experimental-strip-types` so they import `src/content/types.ts` and `src/content/ruby.ts` directly (no duplicated regexes); the audio render pipeline (`scripts/audio/*.ts`, design 08 §7; runbook `docs/AUDIO_PACK.md`) may additionally import **`src/shared/speak-text.ts`** (`textToSpeak(toPlain(ja), kana)` is the text handed to VOICEVOX, so clip and caller agree), **`src/shared/jp.ts`** (`moraSplit` / `moraCount` / `speechMorae` / `expandLongVowelMark` / `normalizeAnswer`: the per-clip mora verification and the indexes' `m` / `c` cues count with the same body the validator and the linker use) and **`src/learn/distractors.ts`** (`scripts/audio/verify.ts` re-exports `synthesizeMinimalPair` from it for the `<itemId>#pair` clip text, so the っ rule is one body; `distractors.test.ts` spawns `node` to keep the module importable); `scripts/linker.ts` and `scripts/listening-report.ts` import `src/shared/jp.ts` too (`speechMorae` for the pool `morae` field and the hours estimate). Scripts use `node:fs` / `node:path` / `node:crypto` / `node:child_process` for the file walk, the hashes and the `ffmpeg` / `tar` shell-outs; nothing under `src/` does. The rule for a script-importable module: pure, no store or signals import, every relative import carries its `.ts` extension (`speak-text.test.ts`, `distractors.test.ts` and `render-audio.test.ts` spawn `node` to prove it); `src/audio/tts.ts` is NOT importable (extension-less `../content/ruby`, `store` import) and never will be; `scripts/linker.ts` is the token → item matcher (`buildMatchPool` / `matchToken` / `inflectedForms`) shared by `content:assign` and the validator (`assign-stations.ts` re-exports it), so `StoryLine.tokenIds` and V19 / V20 / V36 agree by construction — and, since design 08 §4, the sentence segmenter (`segmentSentence` / `linkSentence` / `buildPools`) that writes `public/content/listening/pool-NN.json` and arbitrates V46. `npm run content:all` is validate → assign → index → `content:report` (`scripts/listening-report.ts` → `docs/listening-report.md`) → `content:validate -- --strict --listening-release` (the release gate: V43 / V45 / V46 at Stations 4–15 as F; 0 F on the landed tree, byte-stable under a second run), and `content:index`'s default check enforces V44 and the pool budget `POOL_FILE_BUDGET_BYTES` (256 KiB, hard). The art tier is reached through two barrels: `src/art/index.ts` (boot: `DojoScene`, `CeremonyHost`, `MonCrest`, `GoshuinStamp`) and `src/art/studio.ts` (wallpapers + PNG export, Studio / Collections only). - **Print pack scripts** (`scripts/art/*.ts`, design 09 §12.1 d77–d78; runbook `docs/ART_PACK.md`) mirror `scripts/audio/*`: `art:source` (curation `scripts/art/curation/*.json` → Art Institute of Chicago record, `is_public_domain` asserted → IIIF JPEG → `cwebp` → `public/art/manifest.json`, `tsuzuku.art/1`), `art:check`, `art:pack`, `art:publish` (a dry run unless `--yes`) and `art:fetch`, which calls `scripts/audio/fetch-audio-pack.ts`'s `fetchAudioPack` with the art pointer (`public/art-pack.json`, `tsuzuku.art-pack/1` — the audio pointer's shape with `artVersion`; the fetch reads either through `PointerLike` and takes `noneMessage` / `label`). ## 1. Store (`src/shared/store-types.ts`; API `src/store/index.ts`, B)

`backup.applyImport` is atomic (the pure merge first, in one signals batch; a throw inside the write batch restores meta, cards, log and session before rethrowing), clears the in-progress session snapshot in both modes, refuses an import over `IMPORT_MAX_BYTES` (32 MB — file, text or inflated gzip output) before parsing, and `migrateShard` refuses an unknown `level`; `mergeSaves` takes the backup's identity (name, nameKana, tz, onboardedAt, dictatedSentence) when this browser has no learner trace (`hasNoLearnerTrace`, the same rule as `app/first-run.ts`). `mergeLedger` (design 08 §12): app rows (source app, no note) are compared per day and kind and the side with the larger sum keeps its rows (tie → this browser's), because same-day `listen:played` rows coalesce into one growing row (`store/ledger.ts withCoalescedEntry`, tenths of a minute via `MINUTE_DECIMALS`); outside and noted rows still union by identity. `Profile.onboardedAt` is written by `OnboardingPage.finish()` (`store.now()`); the store only carries and merges it. The name step is `src/app/names` (A): `<NameField>` over `suggestName` (`index.ts`; `ALL_NAMES`, 1,043 `[latin, kana, romaji]` rows whose romaji round-trip through `finalizeIme(…, { katakana: true })` to the kana, pinned by `names.test.ts`), and `resolveName(draft)` / `isKanaName` decide what `finish()` writes into `name` / `nameKana`. `Profile.dictatedSentence` (plain surface, newest wins; `fillMeta` caps it at 500) is written by two paths: the Listening Arena's `submitDictation` (`src/input/listening/ListeningArena.tsx`) and the sessions' Sentence Dictation drill (`src/exercises/listening/SentenceListen.tsx`) — both on a perfect dictation (Good band, no hint, under the replay ceiling) at a rate ≥ `DICTATED_MIN_RATE` (1×, exported by each since D cannot import `src/input`); the Waveform kakejiku reads it. `OnboardingPage` value-imports `onboardingEstimate` from `@/store/derived` (contract path) and shows the store's pacing estimate per preset (`roadEstimateFor`); its `ROAD_DAYS` table is only the fallback when no estimate can be computed. Re-initialising the store (`initStore` again, slot switch) flushes the outgoing slot's pending writes before teardown. `storage.level === 'ceiling'` also means a write is failing or a key is frozen (an unreadable document whose `.bak` stash itself hit the quota): the shell copy says progress may not be saving. Daily quests: `store/quests.ts` draws three quests per (seed, day) with a variety rule (never two from one strand) and a per-quest availability gate — `hasFacet` (pitch-five needs a `#pitch` card) and `canDo`, fed by the day gates `setQuestGates(day, closed)` / `questClosed(id, day)`: `pickDailyQuests` skips a closed quest unless today's slice already has it done, gates keyed to another day are ignored, and the `session:started` reducer calls `revalidateQuests(store)`. Nothing outside the store calls `setQuestGates` yet (the session layer should declare `learn-scroll` / `michikusa-one` closed when no Scroll or fresh fragment remains). Keys `tsuzuku.meta.v1[.slot]`, `tsuzuku.cards.v1.<kind>.<level>[.slot]` (`CardShard` carries `kind` **and** `level` from day 0: `vocab.n5 … vocab.n1`, `kanji.n5 … kanji.n2`, `grammar.n5 … n1`, `kana.kana`, `misc.kana` for components/chunks; a review rewrites ≤ 450 KB), `tsuzuku.log.v1[.slot]`, `tsuzuku.session.v1[.slot]`; debounce 1 s/shard, flush on `visibilitychange|pagehide`. **Bytes are UTF-16:** `bytes(str) = str.length * 2`; warn **3.5 MB**, ceiling **4.5 MB** of the 5 MB quota (ceiling = log ring → 2,000, daily rows > 2 y → monthly, then `CompressionStream('gzip')` on the largest shard); only B touches storage. An unreadable meta, card shard or review log is stashed as `<key>.bak` (never deleted; a stash that itself hits the quota frees the session key, retries once, then `persist.freeze(key)` leaves the original in place and the level reads `ceiling`). `migrateMeta` runs `profile.tz` through `shared/time.safeTz` (shape check + `Intl` probe, else `'UTC'`), so every tz consumer can trust the saved zone.

## 3. Content loader (`src/content/loader.ts`, C)
```ts
type ContentItem = KanaItem|VocabItem|KanjiItem|GrammarItem|StoryItem|MichikusaItem|ComponentDef;
interface ContentLoader {
  manifest():Promise<ContentManifest>; station(n):Promise<StationBundle>; cumulative(n):Promise<Record<'kanaIds'|'vocabIds'|'kanjiIds'|'grammarIds',Set<s>>>;  // all stations <= n
  load(ids:s[]):Promise<void>; preloadStation(n):Promise<void>; prefetchStation(n):void;
  get<T extends ContentItem=ContentItem>(id:s):T|undefined;   // SYNC, memory cache
  getAsync<T extends ContentItem=ContentItem>(id:s):Promise<T|undefined>;   // loads the one file that holds `id` on demand (Gloss tap, capture)
  components():Promise<Map<s,ComponentDef>>;
  resolveId(id:s):s; stationOf(id:s):n|undefined; kindOf(id:s):IdKind; version:Signal<s|null>;
  pool(n):Promise<ListeningPool>;   // design 08 §4: listening/pool-NN.json via the manifest's type 'pool' file for n (cached, Cache-API mirrored); rejects ContentError('missing-pool') with no fetch when none is listed
}
export const content:ContentLoader; export function createLoader(fetchImpl?:typeof fetch,base?:s):ContentLoader;
type IdKind = ItemKind|'story'|'michikusa'|'conjugation'|'station';   // shared/ids.ts; `kindOfId` and `kindOf` return the same union
type ContentErrorCode = 'http'|'parse'|'schema'|'missing-station'|'missing-pool';
```
Listening pools (design 08 §4): `listening/pool-NN.json` is a `ListeningPool` (`tsuzuku.pool/1`, `PoolRef { ref, ids, kana, morae }`) generated by `content:assign`, listed in the manifest as `type: 'pool'`, `stations: [NN]`, and is **not** a ContentFile — pool files never enter the id → file lookup, the item index or `preloadStation` (the `NON_ITEM_KINDS` set, with `station` and `conjugation`). Audio-first pieces live in `stories/<level>/listening-sNN.json` beside `stories-sNN.json` and need no loader change (the `stations` filter already returns every story file of the id's station). The selector over pools is `@/learn` `selectPool(refs, known, cards, today, { mode: 'i+0' | 'i+1', limit? })` / `poolMinutes(refs)` / `plusOneId(ref, known)` (`learn/pool.ts`): i+0 = every id in `knownSet`; i+1 = exactly one unknown id whose `listen` card EXISTS and is due within `IMPLICIT_WINDOW_DAYS` (3) or not yet in review state; input order preserved.
Station entry stays lazy: a story opens with **only the learner's cards + the story file** because `StoryLine.tokenIds` (generated by the linker) names the item behind every token and `StationBundle.surfaces` (surface → id for the cumulative allowlist) covers non-story text; `get()` is never required for allowlist items that are not loaded, and Gloss uses `getAsync(id)` on tap. The conjugation golden table (`conjugation/*.json`, ≈ 903 rows) is **not** exposed by the loader; only `learn/conjugate.test.ts` reads it from disk. Kanji ids carry no level, so a kanji lookup without a bundle hint scans the kanji files in **introduction order** (ascending first `ManifestFile.stations` entry: n5 → n4 → n3 → n2) and stops at the holding file; later-level files are never fetched first. The Cache API mirror `tsuzuku-content-<contentVersion>` is the only offline store for `content/**` (`sw.js` leaves content alone): a new `contentVersion` opens a fresh mirror and prunes the old one.

## 8. Conventions
- Files `kebab-case.ts`; components `PascalCase.tsx`; pages `*Page.tsx` under `<group>/pages/`. **Default export only for pages**; all else named. Tests beside modules as `name.test.ts(x)`.
- Engines pure (`now`, `rng`, `day` injected), table-driven; each group ships the test doubles others need (`store/testing.ts`, `content/fixtures`, `bus.reset()`, `nullAudio`). TS strict, no `any`; no `Math.random`/`Date.now` outside `shared/hash.ts` and `store.now()`.
- UI copy in each folder's `strings.ts` (Sensei voice), linted by `src/i18n/banned.test.ts`. Japanese text carries `lang="ja"`. Module-level signals only in `store`.
- Architecture lints (`src/i18n/lint.test.ts`, A): 1 inline English in JSX → strings.ts; 2 no `Math.random` / `Date.now` outside `shared/hash.ts`, `store/store.ts`, `main.tsx`; 3 default exports only in `pages/`; 4 the import rule above (type-only imports allowed); 5 no `autoFocus` attribute on an intrinsic element (`<button>`, `<input>`, `<textarea>`, `<select>`, `<a>`) in any `.tsx` — use `useAutoFocus(ref, deps)` from `shared/ui/use-auto-focus` or a component's `autoFocus` prop (`KanaInput` / `TextAnswer`, which focus imperatively).
- Phases `[P1]-[P3]` are tagged in the module plan; an unregistered exercise is skipped by the builder. No new runtime deps; nothing is ever deleted from a save (archive = flag).
- "Mature" means **the facet being tested has S ≥ 14 d** (`learn/grading.ts isMature`); every timer, speed ring, Flash/Strike sample, Kage speed half and Rapid Fire pool uses that one definition.
